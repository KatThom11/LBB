Each original is 1536×1920. The 640×800 WebP derivatives preserve the full composition and ivory background; they total approximately 184 KB. Original PNGs are preserved here for future editing. The preview server serves the four explicit WebP paths; it does not expose this directory or source files as a file browser.

The Cart keeps its brass-and-teal body, four face-bearing drawers, butterfly emblem, push handle, cards, and wheels. The expressions are illustrations of the fictional guide's activity, not judgments of the visitor or verification of a reply. All four can be viewed in **Explore → Meet the Exhibit Cart** without leaving the current conversation.

`provenance.json` records the original reference task, generation task IDs, model reported by Runway, and the requested pose variations. Signed download URLs and credentials are deliberately omitted. No live image generation happens in the website.
